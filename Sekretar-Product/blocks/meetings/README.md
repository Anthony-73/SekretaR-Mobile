# Meetings Block

Meetings is responsible for meeting lifecycle and meeting artifacts.

Meeting is important, but it is not the center of SekretaR.

Responsibilities:

- meeting identity;
- upload lifecycle;
- processing status;
- transcript references;
- summary references;
- extracted task references;
- links to memory sources;
- links to artifacts.

Meetings should produce structured sources for Memory, Tasks, Research, and Assistant instead of owning those blocks.
