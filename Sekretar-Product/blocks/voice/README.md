# Voice Block

Voice is a future block for the voice assistant experience.

It may reuse ideas from Nafanya later, but it is not implemented in this skeleton.

Future responsibilities:

- voice sessions;
- speech input;
- speech output;
- conversational state;
- explanation of meeting results;
- memory-based answers;
- research and task status explanations.

Voice should use Assistant and Memory through contracts instead of reading product data directly.
