# Projects Block

Projects is a future block for personal and work project structure.

Projects connect meetings, tasks, decisions, people, research, documents, and memory entries.

Future responsibilities:

- project identity;
- project status;
- project knowledge;
- links to meetings and tasks;
- project-level decisions;
- project-specific research briefings.

Projects should not be inferred as a flat tag list only. They need lifecycle and relationships.
