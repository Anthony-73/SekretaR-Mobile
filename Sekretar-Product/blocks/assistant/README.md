# Assistant Block

Assistant is a future block for personal AI assistance.

It will use User Context, Memory, Projects, Goals, Research Intelligence, and External LLM Gateway.

Future responsibilities:

- answering questions using user memory;
- explaining meeting results;
- comparing past decisions;
- helping with task preparation;
- reasoning across projects and goals;
- deciding which context is needed for a user request.

Assistant should not own Memory. It should retrieve and use Memory through clear contracts.
