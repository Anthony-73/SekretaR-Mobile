# Billing Block

Billing owns product economy and credit accounting.

Billing is separate from Identity and Security. It does not authorize users and does not enforce security decisions.

## Responsibilities

- virtual credits;
- real credits;
- tariffs;
- credit packages;
- trial periods;
- product limits;
- accrual history;
- spending history;
- future payment systems.

Billing provides Capability Service with information about available user features and limits.

## Beta Billing

For Beta 2, SekretaR should use virtual credits.

The user receives a starting test balance. Credits model future product economics before real payments are connected.

Beta goals:

- measure feature consumption;
- estimate scenario costs;
- understand user value;
- test Billing behavior before payments.

## Production Billing

The virtual credit model may continue in production.

Users may buy credit packages, for example:

- 20 credits;
- 40 credits;
- 100 credits.

Larger packages may reduce the effective cost per meeting or advanced feature.

## Free Mode

New users receive an introductory period with full access.

After the introductory period, the user chooses:

1. stay on the free tier;
2. use credits.

Free mode may include:

- Recorder;
- file upload;
- transcription;
- history;
- calendar.

Credit-based advanced functions may include:

- Memory;
- Research Intelligence;
- Assistant;
- Voice Assistant.
