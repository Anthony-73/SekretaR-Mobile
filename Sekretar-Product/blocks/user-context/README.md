# User Context Block

User Context represents the user's current working context.

It is separate from long-term Memory. Memory stores durable knowledge; User Context stores current focus, recent activity, active topics, and short-term state.

Future responsibilities:

- active user focus;
- recent meetings and tasks;
- active projects;
- current assistant context;
- temporary context windows.

User Context should be derived and refreshable, not an unbounded storage dump.
