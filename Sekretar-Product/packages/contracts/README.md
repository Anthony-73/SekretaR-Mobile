# Contracts

Contracts define shared API and event shapes.

Contracts to fix early:

- identity registration and login;
- device registration and management;
- session lifecycle;
- recorder capability check;
- meeting creation;
- upload init;
- upload chunk;
- upload complete;
- meeting status;
- job status;
- speaker intelligence result;
- structured transcript;
- task confirmation;
- memory source registration;
- research briefing request;
- billing balance and feature limits;
- security event;
- Trust Score signal;
- capability response.

Contracts should be versioned before multiple clients depend on them.
