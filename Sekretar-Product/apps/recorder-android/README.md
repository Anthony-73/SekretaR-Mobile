# Recorder Android

Recorder Android is Recorder V2 and is a first-class part of SekretaR.

Recorder starts the meeting lifecycle. It is not an external app and not a side integration.

Responsibilities:

- creating local meeting identity;
- recording audio;
- keeping upload state;
- chunk upload;
- retry and resume;
- sending device and capability metadata;
- handing control back to the product experience after upload.

This folder is reserved for the Android Studio project or a linked Android workspace. Existing Recorder code is not copied here at this stage.
